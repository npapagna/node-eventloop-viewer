                Counts: each timer, immediate, I/O and 'close' callback Node calls from the loop, and
                the main script. Node drains these queues when that call returns to it (between timers and between
                immediates, it drains explicitly).
Does not count: functions you call yourself, such as a
                forEach callback or a listener called by emit(). They run inside the current
                callback, so the drain waits for that outer callback to return.
                Docs: Event loop guide
